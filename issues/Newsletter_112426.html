Front Page

Hardware Forensics

The Counter That Can Be Rewound: Rolling Back the TPM Lockout Cuts a BitLocker PIN From Years to Days

A Technische Universität Berlin paper posted to arXiv on November 18 attacks the one control that makes a short PIN safe. On the machines tested the TPM is firmware inside the processor with no secure storage of its own, so its state — including the count of wrong guesses — is held encrypted on the mainboard flash chip. Copy that state, guess until the lockout bites, write the old copy back, and the count reverts. Newer boards defend this with RPMC, monotonic counters inside the flash chip that only rise; the researchers report that AMD processor firmware never verifies the counter moved, so an interposer board between CPU and flash blocks the update and reports success. Winbond RPMC chips on some boards also leak the key that signs counter values under a brief voltage glitch, extracted in about a second, so the forgery is not limited to AMD.

Measured results: a four-digit Windows Hello PIN fell after 236 tries in 57 minutes on an AMD laptop, and a six-digit BitLocker startup PIN after 236 tries in 6 minutes 55 seconds on an Intel one. Extrapolated worst cases drop a four-digit PIN from 69 days to 40 hours and a six-digit BitLocker PIN from 19 years to 20 days. AMD assigned CVE-2026-43613 at CVSS 5.1 and schedules firmware fixes into February while calling physical-access attacks outside its threat model; Intel says no Intel component was shown vulnerable; Microsoft rated the Hello report moderate, issued no CVE, and is raising its recommended minimum Hello PIN to six digits. Forensic priority: this is lab work needing the chip desoldered and a custom board, but it undoes the reasoning behind TPM+PIN — and a lockout counter that can be rewound is not a reliable record of how many times a device was attacked.

Device Forensics

The Vendor Fixed Its Cloud, and the Only Remedy Left Destroys the Evidence on the Device

GL.iNet advised on November 20 that an unauthorised party had abused a flaw in its GoodCloud remote-management service to install malware on routers and KVM devices. Customers and researchers reported custom implants built for the hardware plus root-level reverse shells beaconing to a single address; one component installs attacker SSH keys, alters file timestamps, and polls a remote server for commands. The company closed the access route on its own infrastructure, which stops new compromises and cleans nothing — owners must reflash the security firmware for their model. One reseller checking roughly two hundred routers reported most appeared affected, by this intrusion or by an older backdoor apparently dating to September 2025.

For an examiner this is three problems at once. The implant timestomps, so the file system's chronology is suspect and corroboration must come from the vendor's cloud-side logs rather than the device. The recommended remediation — reflash without preserving settings — is also the most thorough evidence destruction available, so an image has to precede it. And because stored secrets are exposed by assumption, the incident does not end at the device: VPN keys, Wi-Fi and administrative passwords, cloud credentials and SSH keys are all compromised. Forensic priority: image before you reflash, and pull the management-cloud audit trail while the vendor still has it.

Threat Bulletin

Active Exploit

CVE-2026-123890 — Broadcom VMware vCenter. An authentication bypass in the VMware Directory Service, the identity store behind vCenter Single Sign-On, lets an unauthenticated attacker with network access reach administrator@vsphere.local; CVSS 9.8. Mandiant and Google Threat Intelligence attribute zero-day use since early September to a suspected PRC-nexus group, with the directory store exfiltrated, the SAML token service hijacked and an SSO administrator account added. Fixed November 19 in vCenter 9.1.1.0200, 9.0.2.0200 and 8.0 U3m; CISA KEV November 20. Forensic Note: Rebuilding vCenter while the old SAML signing key stays valid leaves previously forged tokens working — rotate the key, not just the host.

Active Exploit

CVE-2026-76466 — Cisco Expressway Series. Clustered Expressway-C and Expressway-E ship a hard-coded credential for the database service, so an unauthenticated attacker with network access runs commands as root; CVSS 9.8, and the factory-default TLS mode does not verify client certificates. Fixed in X15.5.20 with no workaround; CISA KEV November 20, and public exploit code exists. Forensic Note: The credential is shared across the cluster, so one compromised node puts every member in scope.

Malware Spotlight

ZQAgent — NVISO published analysis on November 23 of a Linux backdoor it saw installed during a Belgian incident response by the AI-driven intrusion framework this newsletter has tracked since October. The sample is named to resemble a time service, copies itself into an anonymous in-memory file, then relaunches detached under the name of the system message-bus daemon. It executes commands, reads files and tunnels network traffic. Infrastructure ties it to a cluster reported in Asia against government and human-rights targets, at low confidence. Forensic Note: The running process has no file behind it — its executable path is a memory descriptor marked deleted — but persistence is ordinary, so the systemd unit and cron entry are what a disk image will hold.

Case Studies: Historical Grid

The Melissa Virus (1999)

The First Mass-Mailer Case, and an Author Found Through the Accounts He Borrowed

Melissa appeared on March 26, 1999 as an infected Word document posted to the alt.sex newsgroup, mailing itself onward to the first fifty entries of each victim's Outlook address book and forcing organisations including Microsoft and Intel to shut their mail gateways. The investigative thread was not the macro. The posting had been made through a hijacked AOL account belonging to an uninvolved engineer in Washington state, and AOL's own records placed the session in New Jersey; David L. Smith was arrested in Eatontown on April 1, a week after release. Contemporary reporting also credits the document GUID embedded by Word, which an infrastructure-protection specialist said at the time would be a factor — how far it carried the identification was never set out publicly, and that gap is itself instructive. Smith pleaded guilty and served 20 months. The lasting lesson is that the earliest reliable identifier was metadata and account provenance the author had no idea he was generating.

Bitfinex — Lichtenstein and Morgan (2016–2024)

Six Years of Laundering Undone by One Encrypted File in a Cloud Storage Account

Roughly 119,750 bitcoin left Bitfinex in August 2016 in some two thousand transactions, and for six years the proceeds moved through mixers, darknet markets and accounts opened under fabricated identities. What ended it was ordinary evidence handling. Blockchain tracing narrowed the flows to wallets associated with Ilya Lichtenstein and Heather Morgan; a warrant then reached Lichtenstein's cloud storage account, where agents decrypted a file holding the addresses used to move the funds together with their private keys. That one artefact enabled the seizure of about 94,000 bitcoin, roughly $3.6 billion, the largest financial seizure in Department of Justice history at the time. Both pleaded guilty to money laundering conspiracy in 2023; Lichtenstein was sentenced to five years and Morgan to eighteen months. Pseudonymous value is traceable, but the decisive material was a convenience backup an operator kept in someone else's infrastructure.

Operation Ghost Click — DNSChanger (2011–2012)

When the Only Census of the Victims Was the Infrastructure the Police Had Just Seized

DNSChanger, run from Estonia by the Rove Digital operation, rewrote an infected machine's DNS settings so every lookup went to servers the criminals controlled. A two-year FBI investigation ended in November 2011 with arrests, but pulling the rogue resolvers offline would have cut every victim off the internet — so a court authorised clean replacements, shut down on July 9, 2012. For those months the resolver in the middle was the only instrument that could count the infected, and the counts still disagreed: F-Secure estimated around 300,000 machines remaining in early July while figures attributed to the FBI put it an order of magnitude lower. A measurement point inherited from the attacker tells you who is still talking to it, which is not the same question as who is still infected.

Operation Trojan Shield — ANOM (2018–2021)

The Platform Was the Evidence: Three Years of Messages From a Network the Investigators Owned

After a 2018 arrest removed one encrypted-handset provider from the market, the FBI and the Australian Federal Police filled the gap themselves, distributing hardened phones running the ANOM application through the criminal resellers the market already trusted. Users believed they were buying end-to-end encryption; the platform in the middle was operated by the investigators, and the product was a complete evidentiary record generated by design rather than an intercept bolted onto another network. The operation was revealed on June 8, 2021, the Justice Department citing more than 800 arrests worldwide. It set the admissibility arguments that followed: when the state designs the system that produces the record, provenance and lawful authority become the contested ground rather than the data.

Tools of the Trade

Commercial

iOS Forensic Toolkit

10.13 — Elcomsoft

Extends agent-based file system extraction to the full iOS and iPadOS 26 range, 26.0 through 26.7.3, where application data that never reaches a backup lives. The vendor has also signalled a command-line-only build published as Python source.

Open Source

ExifTool

13.64 — Phil Harvey

The reference reader and writer for embedded metadata across images, video, audio and documents, covering hundreds of formats and tag sets. It remains the tool that answers what a file records about its own creation — the question that identified the author of Melissa.

Utility / Script

IRMind

v0.6.0 — Anibal Cañada

A terminal assistant for incident response that keeps a signed record of the session, so what the examiner asked and what it answered are both auditable afterwards. Treat it as a notebook with provenance, not an analyst.

Open Source

pySigma

v2.1.1 — SigmaHQ

The Python library behind the Sigma rule format, parsing and validating rules and compiling them to the query language of a given backend. Useful this week for turning a published detection — a deleted memory-descriptor executable path — into a query your platform will run.

Priority CVE Advisories

Archive Alert CVE-2026-115731 (Perforce Puppet Enterprise)

Unsafe deserialization in report processing lets a client holding any CA-signed agent certificate run code on the Puppet Server as the service user; CVSS 9.9, CISA KEV November 17. Forensic Note: The agent report is the attack path, so every node that submitted one is in scope.

Archive Alert CVE-2026-123039 (Check Point Gaia OS)

The DynamicCLI daemon runs as root on a world-writable local socket without authenticating the connecting process, so any local user reaches root; CISA KEV November 13. Forensic Note: A snapshot taken after October 30 can restore the backdoor with the configuration.

Recent Malware Watch

Archive: November 17, 2026 Cursor Marketplace Cache Poisoning — Eleven Hours of Bad Builds

A credential recovered from coding-agent traces at a third-party inference provider placed malicious extension builds into the cache serving Cursor's marketplace. The artefact on a workstation is an authorized_keys entry and an sshd change, not a file to scan for.

Archive: November 10, 2026 cPGuard Update Hijack — Seventy-Two Minutes of Victims

Stolen credentials reached the vendor's update infrastructure and pushed a script that around 2,950 Linux servers ran as root between 02:08 and 03:20 UTC. The fix removes the backdoor and the staged files together, so imaging comes first.
