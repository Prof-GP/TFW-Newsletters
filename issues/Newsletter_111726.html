Front Page

Mobile Forensics

The Courier Keeps a Copy: Push Notification Records Belong to Play Services, Not to the App You Deleted

GMDSOFT technical analysis, carried by Forensic Focus on November 11, triggered Firebase Cloud Messaging data messages across LINE, Telegram, KakaoTalk, Signal, WhatsApp, TikTok and BAND, then examined what the handset kept. Records from every application tested landed in a single LevelDB-based store inside the Google Play Services data area, com.google.android.gms, sharing one common key-value structure, and each record identified the receiving application and the time the message arrived.

Three payload patterns emerged: plain text that is readable once decoded, a body that is present but encrypted, and records that are metadata only — proof a message arrived with no content attached. The structural point is the one worth carrying into a case: the store belongs to Play Services rather than to the application, so removing the application does not by itself remove the record of what it received. Forensic priority: treat the Play Services data area as a communications source in its own right and check it when an application of interest is absent from the device. The same logic reaches past push notifications: wherever a platform component handles data on an application's behalf, what is retained is governed by the platform rather than by the application's own cleanup. The authors are explicit about the limits — FCM artefacts do not replace application-level analysis, and the storage format varies across application versions, so decode results from one case do not transfer unverified to the next.

Incident Response

288 Endpoints in Ninety Minutes, and the Only Tell Was a Command With No Login Behind It

Attackers reached cloud-hosted ScreenConnect instances on November 11 and used the platform's own Run Command feature to install rogue clients across managed endpoints. Huntress put the confirmed scope at a minimum of 288 endpoints across 48 organisations, every one touched inside ninety minutes and about a third within the first ten. Initial access is attributed to RMM+, a third-party ScreenConnect extension whose versions 1.0.31 and 1.0.32 left a shared access key blank when no administrator had set one; supplying an empty key issued commands without a ScreenConnect login or MFA. ConnectWise disabled five potentially related extensions across roughly 400 partner environments.

The toolkit recovered afterwards, named SCKit by Huntress and Blackpoint Cyber, is sixteen scripts and components built to climb from the customer endpoint back to the technician. RelayTrap ships as C# source compiled locally by a PowerShell script, replaces the legitimate ScreenConnect Guest process and waits for a technician to connect, while TrapWatch monitors the services to prepare the swap; other components steal ScreenConnect session cookies from browsers. Neither firm observed that climb succeed, and Blackpoint reproduced the file-transfer exploit against a current client and watched the patch hold. Forensic priority: what exposed this was the platform log showing commands executed with no matching user login — audit the management console before the endpoints, and do not open an interactive session to a host you suspect.

Threat Bulletin

Active Exploit

CVE-2026-115731 — Perforce Puppet Enterprise. Unsafe deserialization in Puppet's report-processing code lets a client holding any CA-signed agent certificate run code on the Puppet Server as the service user, by submitting a report carrying a crafted rich-data type in a PUT request; CVSS 9.9. Where the certificate authority autosigns requests without strong verification, obtaining that certificate is itself unauthenticated. Fixed in Puppet Enterprise 2026.0.1, 2025.12.1 and 2023.8.13; CISA KEV November 17, due December 1, with public exploit code available. Forensic Note: The agent report is the attack path, so every node that submitted one is in scope — review Puppet Server logs for processes spawned by the service account.

Active Exploit

CVE-2026-123039 — Check Point Gaia OS. The DynamicCLI daemon runs as root and listens on a world-writable local socket without authenticating the process that connects, so any authenticated local user reaches root; CVSS 7.8, R81 through R82.20. Check Point reports it chained behind the PHP2Shell flaws against Mobile Access portals from October 30, planting the TSGA backdoor; some victims then lost an ESXi host to a wiper reached over SSH. CISA KEV November 13. Forensic Note: A Gaia snapshot or backup taken after October 30 can restore the backdoor with the configuration — validate the restore point before you roll back to it.

Malware Spotlight

Cursor Marketplace Cache Poisoning — On November 14 Cursor confirmed that attackers used an access key held at Fireworks AI, its third-party inference provider, to read a bucket of 2025 coding-agent traces holding unredacted API credentials. One of those credentials placed malicious copies of Anthropic's Claude Code extension, versions 2.1.312 and 2.1.313, into the cache serving Cursor's extension marketplace on October 29. They were live about eleven hours; up to 5,000 users may have fetched them. Forensic Note: The payload installed an attacker-controlled SSH key and tried to enable SSH, so the artefact on a developer workstation is an authorized_keys entry and an sshd configuration change — not a file on disk to scan for.

Case Studies: Historical Grid

Operation Ghost Click — DNSChanger (2011–2012)

When the Only Census of the Victims Was the Infrastructure the Police Had Just Seized

DNSChanger, run from Estonia by the Rove Digital operation, worked by rewriting an infected machine's DNS settings so that every lookup it made went to servers the criminals controlled. A two-year FBI investigation ended in November 2011 with an unsealed indictment and arrests carried out with NASA's Office of Inspector General and Estonian police. The problem the takedown created is the one worth remembering: pulling the rogue resolvers offline would have cut every victim off the internet, so in March 2012 a court authorised the Internet Systems Consortium to run clean replacement servers in their place, shut down on July 9, 2012. For those months the resolver in the middle was the only instrument that could count the infected — and the counts still disagreed, with F-Secure estimating around 300,000 machines remaining in early July while figures attributed to the FBI put it an order of magnitude lower. A measurement point you inherit from the attacker tells you who is still talking to it, which is not the same question as who is still infected.

Operation Trojan Shield — ANOM (2018–2021)

The Platform Was the Evidence: Three Years of Messages From a Network the Investigators Owned

After the FBI's 2018 arrest of Vincent Ramos of Phantom Secure removed one encrypted-handset provider from the market, the FBI and the Australian Federal Police filled the gap themselves, distributing hardened phones running the ANOM application through the same criminal resellers the market already trusted. Users believed they were buying end-to-end encryption; the platform in the middle was operated by the investigators, and the product was not an intercept bolted onto someone else's network but a complete evidentiary record generated by design. The operation was revealed on June 8, 2021, with the Justice Department citing more than 800 arrests worldwide, 17 defendants indicted in the United States, 224 arrests and over 526 charges in Australia, and seizures including eight tonnes of cocaine, 250 firearms and more than $48 million. It also set the admissibility arguments that followed: when the state designs the system that produces the record, provenance and lawful authority become the contested ground rather than the data itself.

Post Office Horizon (1999–2024)

Seven Hundred Prosecutions Built on Software Output Nobody Was Allowed to Doubt

From 1999 the UK Post Office rolled out Fujitsu's Horizon accounting system across its branch network and prosecuted subpostmasters when it reported shortfalls — around seven hundred of them, with 236 people imprisoned. The 2019 High Court litigation in Bates v Post Office, brought by more than 550 claimants, established that the software itself could generate phantom losses, opening the route to appeal; convictions were quashed in waves from December 2020 before Parliament quashed eligible cases in bulk under the Post Office (Horizon System) Offences Act 2024. It remains the reference case for computer-generated evidence treated as reliable by default rather than as a claim to be tested.

State v. Amero (2007)

The Examination That Never Looked for Malware, and the Conviction It Produced

A Connecticut substitute teacher was convicted in January 2007 after pornographic pop-ups appeared on a classroom computer, the case resting on a police examiner who testified that he had relied solely on one commercial tool. The machine was an ageing Windows 98 SE system whose security software licence had expired. An independent review organised by Sunbelt Software's Alex Eckelberry contradicted much of the testimony, and on June 6, 2007 the trial judge threw out the conviction. The prosecution ended in November 2008 without exoneration — a plea to a lesser charge, a $100 fine and a surrendered teaching licence.

Tools of the Trade

Open Source

regfprobe

v0.2.0 — Alexis Brignoni

Reads SYSTEM, SOFTWARE, SAM, NTUSER.DAT and Amcache.hve offline and read-only, straight out of E01 or raw images with no prior extraction. Dirty hives are resolved by replaying transaction logs in memory, with a trust indicator shown to the examiner. One standard-library Python file under MIT, written to be vendored.

Commercial

Belkasoft X

v2.13 — November 2026

Adds deleted-file analysis driven by NTFS Master File Table records, reconstructing entries for deleted files and folders including from volume shadow copies. The index outlives the file, which is the same reason the week's front page works. BelkaGPT now runs on more modest hardware.

Utility / Script

ETW2JSON

Forensic fork — sumeshi

Converts Windows ETL trace files to JSON lines, recording schema provenance for every decode and keeping undecodable events with their raw payload rather than dropping them. The host's own provider registrations are used only behind an explicit flag and labelled as such — so the output states where each field came from.

Open Source

Forensic Media Extractor

v2026.11.327 — ThinkTank4n6

Recovers images and video from E01, raw and VM images, live devices and phone packages through file system parsing, deleted entries and carving, then presents them for grading in a browser backed by a shared hash store. Exports to Project VIC, Griffeye, C4All and LAVA. It deliberately does not classify: categorisation stays with the examiner.

Priority CVE Advisories

Archive Alert CVE-2026-123158 (OpenSSH, “SSHole”)

On Linux built against musl libc where password authentication runs without PAM, an oversized password authenticates as an account with no password set; fixed in 10.6p2, CISA KEV November 9. Forensic Note: There is no failed-login trail because the attempt succeeds — hunt the account, not the event.

Archive Alert CVE-2026-116606 (Barracuda ESG)

An authentication bypass reaching the configuration-import function, letting a crafted backup archive overwrite global settings; chained with CVE-2026-111560 it gives root. CISA KEV November 10. Forensic Note: The intrusion is a configuration restore — capture the configuration and backup history before upgrading.

Recent Malware Watch

Archive: November 10, 2026 cPGuard Update Hijack — Seventy-Two Minutes of Victims

Stolen credentials reached the vendor's update infrastructure and pushed a script that around 2,950 Linux servers ran as root between 02:08 and 03:20 UTC. The fix removes the backdoor and the staged files together, so imaging has to come first.

Archive: November 3, 2026 Skyw4lker — Account Takeover With Nothing on Disk

A device-code phishing kit against Microsoft 365 that steals no password and drops no file: the victim approves an attacker-initiated device-code request on Microsoft's genuine sign-in page. One Entra ID device-code sign-in is the entire artefact.
