Front Page

Network Infrastructure

The Router That Lied to Its Own Admins: Fire Ant Rewrites Cisco IOS XR's Command Line to Hide Its Own Tunnels

Sygnia disclosed this week that the China-nexus actor it tracks as Fire Ant — overlapping with Mandiant's UNC3886 — has expanded a long-running campaign beyond VMware hypervisors to compromise Cisco IOS XR routers, TACACS authentication servers, and the Linux hosts used to manage them. Reverse engineering of the router implant showed it modifies the IOS XR command-execution path itself, appending exclusion filters to "show" commands so that tunnel source, destination, interface, and VRF details never appear to an administrator reading the router's own CLI output — the compromise is invisible from inside the device it lives on.

The campaign introduced two new tools: BridgeAgent, a Linux backdoor for persistence on management hosts, and TacTap, a TACACS credential-harvesting toolkit that injects directly into the running authentication daemon to intercept credentials from inside the process rather than off the wire. Forensic priority: never trust router CLI output alone — pull configuration and state via an out-of-band management path or vendor API and diff it against CLI output for exclusion-filter tampering, hunt TACACS daemon processes for unexpected loaded modules, and treat any Cisco IOS XR device with anomalous VRF or tunnel activity invisible to "show" commands as compromised.

Zero-Day

Two Bugs, No Password: Attackers Chain a PaperCut Auth Bypass Into Unauthenticated Code Execution

PaperCut shipped a second emergency patch this week after researchers and then real-world attackers chained two flaws in its NG/MF print management software into pre-authentication remote code execution. CVE-2026-81578 (CVSS 8.8) lets an unauthenticated request trigger backend administrative actions in the web management interface before access validation completes; from there, an attacker edits a configuration file to reach CVE-2026-82078 (CVSS 9.4), an unsafe dynamic class-loading flaw in PaperCut's database connection utilities that loads driver classes by name with no allowlist. Honeypot telemetry shows exploitation in the wild beginning around August 29, with attackers using the chain to steal data from victim servers.

The class-loading flaw is the more durable lesson: any application that instantiates a class from a configurable, attacker-influenced string is one bypassed check away from remote code execution, regardless of language or framework. Forensic priority: review PaperCut Application Server logs for unauthenticated admin-function requests followed by configuration-file writes, hunt for unexpected JDBC driver class names in server configuration, and treat every unpatched pre-v24 through v26 PaperCut instance reachable from the network as breached until log review proves otherwise.

Malware Spotlight

Nimbus Manticore — Iran's Espionage Toolkit Gets a New Backdoor

Researchers reported August 26 that the Iranian state-sponsored group Nimbus Manticore has expanded its toolset with a TWOSTROKE-like backdoor and a dedicated SSH tunneler, giving operators a durable channel into target networks that blends with legitimate remote-administration traffic. The addition signals a shift toward longer-term network persistence rather than smash-and-grab espionage. Forensic Note: Hunt unexpected outbound SSH tunnel establishment from hosts with no administrative reason to run one, review process ancestry for the new backdoor's loader chain, and treat any unsanctioned SSH tunneling tool as a persistence indicator rather than a misconfiguration.

Case Studies: Historical Grid

SYNful Knock (2015)

The Firmware That Wouldn't Show Itself: How FireEye Found a Persistent Backdoor Hiding Inside Cisco Routers

In September 2015, FireEye's Mandiant unit disclosed SYNful Knock, a modified Cisco IOS firmware image found on routers across four countries that gave attackers persistent, unauthenticated access surviving normal reboots — activated by sending crafted TCP SYN packets to the device, a covert command channel that left no obvious trace in standard configuration review. Because the backdoor lived in the firmware itself rather than in a running process, conventional endpoint detection had nothing to see, and only integrity checks against known-good firmware hashes exposed it. It is a direct ancestor to this week's Fire Ant campaign: the same insight — that the network device administrators trust to tell the truth can be made to lie — now extended from firmware implants to live tampering with the CLI's own output.

Log4Shell (2021)

One Log Line, Total Compromise: How a String Formatter Became the Internet's Worst Zero-Day

In December 2021, researchers disclosed CVE-2021-44228 — Log4Shell — a flaw in the ubiquitous Java logging library Log4j where a single attacker-controlled log message containing a JNDI lookup string could trigger remote class loading and code execution, instantly weaponizable against millions of internet-facing Java applications with zero authentication required. The underlying lesson — that dynamically loading a class or resource based on untrusted input is inherently dangerous, no matter how deep in the application stack it happens — is exactly what this week's PaperCut chain rediscovered four years later in a different language and a different library, the same unsafe pattern wearing a new name.

Duqu (2011)

The Spy Built From Stuxnet's Bones: How a Word Document Zero-Day Turned Industrial Espionage Into Reconnaissance-as-a-Service

In September 2011, researchers at Hungary's CrySyS Lab uncovered Duqu, an espionage tool sharing significant source code with Stuxnet but built for information-gathering rather than sabotage — it arrived via a Microsoft Word document exploiting an unpatched kernel font-parsing zero-day, then quietly harvested keystrokes, system data, and design documents from industrial manufacturers to prepare future attacks. Its shared codebase with Stuxnet became one of the earliest cases where malware genealogy let investigators link a new campaign to an established, state-linked toolkit.

The xz Utils Backdoor (2024)

The Two-Year Con: How a Patient Maintainer Takeover Nearly Backdoored SSH Across Every Major Linux Distribution

In March 2024, Microsoft engineer Andres Freund noticed SSH logins were consuming slightly more CPU than expected and taking a fraction of a second longer — an anomaly he chased into a multi-year social-engineering operation in which a persona named "Jia Tan" had spent two years building trust as a co-maintainer of xz Utils before slipping an obfuscated backdoor into the library's build scripts, positioned to compromise OpenSSH on affected distributions. The backdoor lived in autoconf test files and build-time binary blobs rather than the readable source, precisely so that code review would never catch it.

Tools of the Trade
Open Source

nfdump

SWITCH — v1.7.x

NetFlow/IPFIX collection and analysis toolkit for reconstructing traffic patterns from flow records rather than full packet capture. Ideal for tracing Fire Ant's traffic-collection activity on compromised routers when live packet capture on the device itself can't be trusted.

Open Source

Frida

Frida Project — v17.x

Dynamic instrumentation toolkit for hooking and tracing running processes. Attach it to a PaperCut Application Server (in a sandboxed reproduction) to trace the exact class-loading call path CVE-2026-82078 abuses, confirming which configuration values reached the vulnerable loader on a compromised host.

Commercial

Corelight

Corelight — Sensor v22

Zeek-based network detection and response appliance producing rich, structured logs of every connection. Deploy at network chokepoints around TACACS servers and router management VLANs to catch TacTap's credential-interception traffic and any tunnel activity Fire Ant hides from the router's own CLI.

Utility / Script

Autoruns

Sysinternals — v14.x

The long-standing Windows and Linux autostart-location enumerator. Run it across hosts suspected of hosting Nimbus Manticore's new SSH tunneler to surface unauthorized persistence entries the backdoor needs to survive reboot, alongside any scheduled task launching it silently.
