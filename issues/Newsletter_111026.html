Front Page

Tool Integrity

Forging a Super Timeline From a Cookie: A Plaso Plugin Let the Evidence Overwrite the Tool's Own Metadata

Research published to the OSDFIR blog on October 29 by Joachim Metz, from work by David André, showed that Plaso's Google Analytics __utmz cookie plugin copied key names out of the cookie straight onto the timeline entry as attribute names. A crafted cookie could therefore overwrite the fields Plaso assigns itself — data_type, parser, _parser_chain, source, display_name, filename, url and more — and set the timestamp from the cookie's own time field. It was the only parser found to take attribute names from the data.

The demonstration is the part that matters. Two cookies planted in a Firefox cookie database produced a Chrome history visit to an attacker-chosen URL and a file stat entry for /etc/shadow, both appearing to come from parsers that had never run; the unique_domains_visited analysis plugin then reported the attacker's domain as visited. The tells survive — the path specification still points at cookies.sqlite — but CSV output with a reduced field set hides every one of them. Forensic priority: know which timeline fields come from the data and which from the tool, and verify any entry you would rely on against the original artefact. To audit existing storage files, export to JSON lines and look for entries carrying a cookie_name attribute that are not cookie entries. The fix stores cookie variables as key/value pairs instead; no CVE was assigned.

Policy & Capability

Twenty Thousand Devices in the Queue, and No Record of How Long Any of Them Waits

Answering a parliamentary question on November 3, the UK policing minister told Parliament that “the Home Office does not hold the information requested” when asked how many criminal cases are delayed by digital forensic backlogs, or what the average processing time is. The department's own January 2026 policing white paper put roughly 20,000 devices awaiting analysis at any given time; a 2023 HMICFRS inspection found more than 25,000 and concluded forces were overwhelmed. Remedy is pinned on a new National Police Service and a newly appointed director of forensic services to centralise digital forensics operations.

The backlog is the familiar half of this. The disclosure is that the figure describing it is a stock estimate from a policy document, and that nothing behind it is measured — not queue time, not case impact, not whether any of it is improving. Forensic priority: a number nobody collects cannot be managed and cannot be litigated. Where a device's time in a queue is disclosable, the absence of departmental data does not relieve the lab of its own records, and defence questions about delay, continuity and storage conditions land on the examiner holding the exhibit rather than the minister. Keep your own retention and queue timestamps as if they will be asked for, because they are the only version that exists. A backlog that is estimated rather than measured is also one no centralising body can show it has reduced.

Threat Bulletin

Active Exploit

CVE-2026-123158 — OpenSSH, nicknamed SSHole. In sshd before Portable OpenSSH 10.6p2, on Linux built against musl libc and only where password authentication runs without PAM, an oversized password lets a remote attacker authenticate as an account with no password set. Alpine's default openssh-server is the main exposure; glibc distributions are unaffected. Fixed November 5 and backported by Alpine to every branch from 3.16; CISA KEV November 9. Exploitation reporting is mixed: vendors cite activity in the wild, EPSS sits under one per cent. Forensic Note: There is no failed-login trail, because the attempt succeeds — hunt accepted password authentications for service accounts that should never log in interactively.

Critical

CVE-2026-116606 — Barracuda Email Security Gateway. An authentication bypass (CVSS 9.3) in firmware before 9.4.0.030 lets an unauthenticated attacker reach the configuration-import function and overwrite global settings with a crafted backup archive; chained with the command injection CVE-2026-111560, which also reaches the Load Balancer ADC, Message Archiver and WAF, it gives root. Disclosed November 2; CISA added both to KEV on November 10. The bypass path has not been detailed publicly. Forensic Note: The intrusion is a configuration restore, so the device's own configuration and backup history is the primary artefact — capture it before upgrading.

Malware Spotlight

cPGuard Update Hijack — On November 2 an attacker used stolen credentials to reach OPSSHIELD's update infrastructure and push a malicious script to cPGuard, a Linux web-hosting security suite. Hosts checking for updates between 02:08 and 03:20 UTC ran it as root, installing a backdoor and harvesting password hashes, root database configuration, shell history and SSH keys. Around 2,950 servers ran it. Forensic Note: A 72-minute window defines the entire victim set, so the update log answers the scoping question — but upgrading to 5.88.25 removes the backdoor and the staged files together, destroying the evidence as it remediates. Case Studies: Historical Grid

Post Office Horizon (1999–2024)

Seven Hundred Prosecutions Built on Software Output Nobody Was Allowed to Doubt

From 1999 the UK Post Office rolled out Fujitsu's Horizon accounting system across its branch network, and when the system reported shortfalls it brought prosecutions — around seven hundred of them, with some counts running higher still and 236 people imprisoned. Subpostmasters who said the figures were wrong were told the system could not be. The 2019 High Court litigation in Bates v Post Office, brought by more than 550 claimants, established that the software itself could generate phantom losses, which opened the route to appeal: the first six convictions were quashed in December 2020, thirty-nine in a single 2021 Court of Appeal ruling, and Parliament ultimately quashed eligible convictions in bulk through the Post Office (Horizon System) Offences Act 2024. It is the reference case for what happens when computer-generated evidence is treated as reliable by default rather than as a claim to be tested.

State v. Amero (2007)

The Examination That Never Looked for Malware, and the Conviction It Produced

A Connecticut substitute teacher was convicted in January 2007 of risk of injury to a minor after pornographic pop-ups appeared on a classroom computer, the prosecution case resting on the state's examiner, a Norwich police detective who testified that he had relied solely on one commercial tool for his analysis. The machine was an ageing Windows 98 SE system whose security software licence had expired. An independent review organised by Sunbelt Software's Alex Eckelberry examined the drive and the trial testimony and contradicted much of it, and on June 6, 2007 the trial judge threw out the conviction and ordered a new trial, finding the state's computer witness had given erroneous evidence. The prosecution ended in November 2008 without exoneration — a plea to a lesser charge, a $100 fine and a surrendered teaching licence. The lesson has outlived the hardware: an examination that does not consider the alternative explanation has not tested the hypothesis, it has confirmed it.

Olympic Destroyer (2018)

The Record That Lied: Forged Artefacts Built to Send Investigators After the Wrong Actor

During the Pyeongchang opening ceremony on February 9, 2018, a wiper took down the Games' IT systems, ticketing and venue Wi-Fi. The malware carried forensic artefacts deliberately forged to implicate someone else, including a Rich header crafted to match known Lazarus tooling, and the first wave of attribution duly pointed at North Korea. Kaspersky's analysts unpicked it by showing the header was inconsistent with the rest of the binary. It forced the discipline to treat an artefact's provenance as a question rather than a fact.

TJX (2005–2007)

“We May Never Be Able to Identify”: The Breach Whose Scope Was Never Established

Intruders reached TJX's network in July 2005 through a weakly protected wireless link at a store and went undetected until December 2006. The company reported data taken for at least 45.6 million payment cards; banks in later litigation asserted the figure exceeded 94 million. TJX told the SEC it might never identify much of what was taken, that the intruder's technology had made the contents of most of the 2006 files impossible to determine, and that it had itself deleted many of the affected files in the ordinary course of business.

Tools of the Trade

Open Source

Arsenic Mobile Triage

v4 — North Loop Consulting

Consent-based triage for iOS and Android, released free at version 4. It creates its own backup, parses with explicit timezone handling and reports on communications, which is the right scope for a consensual on-scene review where a full extraction is neither proportionate nor authorised.

Commercial

RabbitHole

v4 — CCL Solutions

Adds parsing for RealmDB and MMKV alongside Mozilla formats, with broader SQLite forensics in this release. RealmDB and MMKV turn up behind mobile applications that leave nothing useful in SQLite, so they are the stores that most often read as an empty result rather than an unsupported one.

Utility / Script

CCTV Log Analyzer

New — via Stark4n6

Extracts system logs from Hikvision, Dahua and TVT DVR and NVR disk images, surfaced in Kevin Pagano's November resource update. Recorder logs carry power cycles, disk events and user access — the context that establishes whether missing footage was overwritten, deleted or never recorded.

Open Source

OrcDecryptNet

New — Intrinsec

A .NET decryptor for DFIR-ORC collection archives, which removes the dependency on the original toolchain to open what a collection produced. Worth having before you need it: an archive you cannot decrypt on the analysis host is an acquisition you cannot use.

Priority CVE Advisories

Archive Alert CVE-2026-119977 (WordPress Core)

Time-of-check/time-of-use race in the predictable, web-reachable staging paths used for full-package core upgrades, giving unauthenticated code execution in the seconds a package is unpacked; fixed in 7.1.4, CISA KEV November 3. Forensic Note: No plugin is involved — hunt unexpected PHP under wp-content/upgrade.

Archive Alert CVE-2026-46300 (Linux kernel, “Fragnesia”)

Local privilege escalation chained behind the PHP2Shell flaws to take root on around twenty-five internet-facing Palo Alto firewalls; CISA KEV October 28. Forensic Note: The KEV entry carries a BOD 26-04 forensic triage requirement — triage before patching.

A device-code phishing kit against Microsoft 365 that steals no password and drops no file: the victim approves an attacker-initiated device-code request on Microsoft's genuine sign-in page. One Entra ID device-code sign-in is the entire artefact.
